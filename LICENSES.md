## Supermarket Operations

- Local file: `tauri-app/public/assets/3d/supermarket-operations.glb`
- Source pack: [3DAssets.dev — Supermarket Operations](https://3dassets.dev/packs/supermarket-operations)
- Source GLB: [starter scene](https://cdn.3dassets.dev/assets/26952/v1/model.glb)
- License: CC0 1.0 Universal; attribution is not required.
- Usage: loaded locally with Three.js `GLTFLoader` as the fixture layer for the SIAMBRUK shop scene. Product quantities and transaction behavior remain SIAMBRUK database data.

## Reviewed but not bundled

- Pocket Diorama Free Sampler: free for personal and commercial projects, but the source page prohibits redistributing the model files. It was not copied into this repository.
- Grab3D Grocery Shelf: CC0 and suitable for integration, but not selected because the Supermarket Operations pack provides a more coherent fixture set for the current scene.
- Tevy checkout counter and village shop URLs: the supplied GLB endpoints could not be inspected reliably, so they were not integrated without license and visual verification.
